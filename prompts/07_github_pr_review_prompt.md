Use GitHub and CodeRabbit as the official review gate for this milestone.

Instructions:
- Create or update a feature branch for the current milestone
- Push the branch to GitHub
- Open a draft pull request
- Use the PR description to summarize scope, testing, and review focus
- Let CodeRabbit review the PR
- Record the important findings in:
  - `07_review/coderabbit_findings.md`
  - `07_review/security_findings.md`
  - `07_review/fix_log.md`

Review focus:
- bugs and regressions
- security vulnerabilities
- auth and authorization flaws
- unsafe API behavior
- data exposure risks
- poor validation or sanitization
- missing tests for risky paths

Do not merge the PR.
Stop after review and ask for approval of Stage 07 only.
