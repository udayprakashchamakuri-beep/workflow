# Implementation Notes

## Milestone 01

Current goal:
- Build the first real front-end foundation for the student syllabus planning website.

What was added:
- `06_build/app/index.html` for the landing page and planning workspace
- `06_build/app/styles.css` for the visual design and responsive layout
- `06_build/app/main.js` for the syllabus form interactions and study-plan preview

What this version does:
- lets the user upload a syllabus file name
- lets the user enter a course name, exam date, weekly study hours, and planning notes
- generates a first-week study plan preview from the selected focus style
- provides a polished front-end base for the next milestone

What is still missing:
- real syllabus parsing
- real AI study-plan generation
- saved user data
- calendar view
- authentication

Next suggested build step:
- connect the front end to a real app structure and a backend/API layer for syllabus extraction and plan generation
